## Ограничения live-проверки
GitHub-hosted runner не является заменой локальной среды пользователя: доступ к localhost:11434 и Telegram Bot API отсутствует. Некоторые площадки могут применять WAF/network restrictions. Поэтому live smoke отчёт должен интерпретироваться по статусу каждой площадки, а не по одному exit code.
