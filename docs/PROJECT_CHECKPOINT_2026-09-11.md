## Проверенные части

- `orchestrator.py`: discovery → global dedup → soft keyword filter → enrichment → strict keyword filter → бизнес-критерии → storage → AI → notification → Excel.
- `Tender` содержит поля, необходимые для бизнес-фильтров и объединения детальной информации с `raw_data`.
- `CriteriaStore` поддерживает отдельные настройки Telegram-пользователей и миграцию старой схемы.
- Scheduler использует APScheduler и timezone из конфигурации.
- В репозитории не найдено `api.openai.com`; проект не переводится на OpenAI.
