# Live проверка площадок

Использовать workflow live-platform-smoke вручную после изменений collector.

## Критерии
- HTTP/Browser доступен.
- Поиск реально отправлен.
- Результатная страница распознана.
- Получен хотя бы один валидный Tender для контрольного запроса, либо явно зафиксирован корректный zero-results ответ.
- WAF/403/timeout/connection reset/parser zero не считать успешным подключением.
- Проверять минимум: ЕИС, B2B-Center, РТС-тендер, Фабрикант, ТМК, Росатом.
- Для JS-площадок использовать Playwright.
- Отчёт сохранять как artifact.

## Важное
Unit tests и GitHub CI не доказывают доступность локального Ollama или Telegram Bot API. Эти сервисы требуют проверки из среды пользователя.
