# Tender Intelligence Agent

Автоматический мониторинг тендеров: поиск на площадках → фильтрация → ИИ-анализ → уведомления в Telegram.

---

## Что делает система

1. По расписанию проверяет тендерные площадки (сейчас — **ЕИС zakupki.gov.ru**).
2. Ищет тендеры по вашим **ключевым словам**.
3. Отсеивает неподходящие по **исключениям**.
4. Анализирует оставшиеся с помощью **ИИ** (или заглушки, пока нет API-ключа).
5. Отправляет подходящие в **Telegram**.
6. **Не дублирует** уже отправленные тендеры.

|-----|-----------|

## Первый запуск (Windows 10)

### Шаг 1. Откройте PowerShell в папке проекта

Папка проекта:
```
C:\Users\Ju4ara\Projects\tender-intelligence-agent
```

### Шаг 2. Создайте виртуальное окружение и установите зависимости

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

### Шаг 3. Создайте файлы настроек

```powershell
copy config\config.example.yaml config\config.yaml
copy config\keywords.example.yaml config\keywords.yaml
copy .env.example .env
```

### Шаг 4. Настройте ключевые слова

Откройте `config\keywords.yaml` в блокноте и измените списки `include` и `exclude` под вашу тематику.

### Шаг 5. (Опционально) Добавьте Telegram и ИИ

Откройте `.env` в блокноте и заполните:

```
TELEGRAM_BOT_TOKEN=ваш_токен_от_BotFather
TELEGRAM_CHAT_ID=ваш_chat_id
AI_API_KEY=ваш_ключ_openai
```

Без токенов система **всё равно работает** — сообщения пишутся в лог (dry-run), а ИИ использует заглушку.

### Шаг 6. Запустите одну проверку (тест)

```powershell
python -m src.main once
```

Или через bat-файл:
```
run.bat once
```

### Шаг 7. Запустите постоянный мониторинг

```powershell
python -m src.main run
```

Программа будет проверять тендеры каждые 60 минут (настраивается в `config\config.yaml`).

Остановка: **Ctrl+C**.

## Настройка без программирования

### Ключевые слова — `config\keywords.yaml`

```yaml
include:
  - "IT-услуги"
  - "разработка программного обеспечения"

exclude:
  - "утилизация"
  - "вывоз мусора"
```

### Расписание и порог — `config\config.yaml`

```yaml
scheduler:
  interval_minutes: 60    # как часто проверять

ai:
  min_relevance_score: 70  # минимальная оценка для Telegram
```

### Секреты — `.env`

Токены и API-ключи **только здесь**, не в yaml-файлах.

## Добавление новых площадок

Архитектура позволяет подключать площадки без переделки ядра:

1. Создаётся новый файл в `src/collectors/` (например, `sberbank_ast.py`).
2. Класс наследует `BaseCollector`.
3. Класс регистрируется в `src/collectors/registry.py`.
4. В `config.yaml` добавляется секция с `enabled: true`.

## ЕИС — как получаются данные

Сборщик использует **официальный публичный поиск** ЕИС:
https://zakupki.gov.ru/epz/order/extendedsearch/

Это тот же поиск, что доступен любому пользователю на сайте. Система:
- делает паузы между запросами;
- не обходит CAPTCHA (при CAPTCHA — останавливает сбор и пишет в лог);
- не использует обход авторизации.

## Частые проблемы

**«python не является внутренней командой»**
→ Переустановите Python с галочкой "Add Python to PATH".

**CAPTCHA на ЕИС**
→ Увеличьте `request_delay_seconds` в config.yaml или уменьшите `interval_minutes`.

**Telegram не приходит**
→ Проверьте токен и chat_id в `.env`. Напишите боту `/start` первым.

**ИИ не работает**
→ Добавьте `AI_API_KEY` в `.env`. Без ключа работает заглушка.
